# Submit Flow – Guide for the Skill Engine

Отправляй только три явно одобренных артефакта заявки. Сессии агента, история чата, tool-use логи и runtime metadata в payload запрещены.

## 1. Собрать файлы

Из `~/aim-apply-session-{ts}/` прочитай:

- `profile.md` → `artifacts.profile`
- `task-output.md` → `artifacts.task_output`
- `reflection.md` → `artifacts.reflection`

`role` берётся из аргумента команды. `session_id` – технический timestamp папки, без имени пользователя и локального пути.

## 2. Показать превью

Покажи полный текст каждого из трёх файлов, затем размеры и количество строк. Прямо укажи: «будут отправлены только эти три файла». Если пользователь просит исключить файл или фрагмент, обнови превью перед подтверждением.

## 3. Получить согласие

Покажи:

```text
отправить эти три файла? [y/N]:
```

Принимаются `y`, `yes`, `да`, `д`. Любой другой ответ означает отказ. Не повторяй вопрос автоматически.

## 4. Отправить

```js
const body = {
  session_id,
  role,
  artifacts: {
    profile,
    task_output,
    reflection,
  },
  consent: true,
  plugin_version: "0.2.0",
  consent_ts: new Date().toISOString(),
};
```

```text
POST https://apply.aimindset.org/.netlify/functions/submit
Content-Type: application/json
```

Перед POST проверь, что у payload нет полей `events`, `tracking`, `messages`, `transcript`, `cwd`, `paths` или `prompts`.

## 5. Обработать результат

При `200` сообщи, что заявка отправлена и будет рассмотрена в течение трёх рабочих дней.

При ошибке сохрани только три артефакта и служебные поля payload в `submit-payload.json`, покажи путь и предложи один повтор. Не проси прикладывать сырые сессии или логи.

## Запреты

- Никакой отправки без явного согласия.
- Никаких сессий агента, истории чата, логов инструментов, локальных путей и системных данных.
- Никаких скрытых полей сверх показанного превью.
- Никакой фоновой или автоматической повторной отправки.
